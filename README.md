# Die Kampagne – Autobattler (Steinheer)

Browser-Autobattler gegen vier KI-Völker. Online: https://steinheer-production.up.railway.app

- `index.html` – das ganze Spiel in einer Datei (gebaut aus den Modulen in `js/`)
- `server.js` – Webserver ohne Abhängigkeiten (`/health`, Bestenliste unter `/api/scores`, gespeichert in `DATA_DIR`)
- `railway.json` – Start und Healthcheck für Railway

Lokal: `npm start` → http://localhost:3000
